## 明确不做

- 补 `domain/` + `usecase/` 四层（ArkTS 无 Flow/Koin）
- 全量拆 `pages/` 到 `feature/`（2–3 万行，等于重做界面层）
- 把 `data/` 算法抽到 `engine/`（不改可测性，反增 import 面）
- 大规模迁移存量 `@State` / `@Prop`（第七.4：存量不动）
- 引入第三方 ORM / DI / 状态库（生态无可安装项）

待评估项：路由改 `NavPathStack`（可减少约 100 处 `AppRoute` 分支，但与六模块无直接关系，先证收益再排期）。
